# Changes to inherited programs

Successful fixtures now expose IO main. Runtime-error fixtures force the original value before returning unit. Records and user datatypes used by print gain explicit fixture-local Show instances; the higher-kinded record uses a concrete case printer. Ambiguous unused parameters get explicit concrete annotations. Compile-error fixtures remain unchanged unless the new main requirement would mask their intended diagnostic.
