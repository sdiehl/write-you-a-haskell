Building
--------

To build the chapters and the book, install Rust, `just`, Boehm GC and LLVM 22.
The pinned book tools are installed locally by `just bootstrap`.

```bash
$ just bootstrap
$ just build
$ just book
```

To generate the pdf:

```bash
$ just pdf
```
